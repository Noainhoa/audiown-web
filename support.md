# Audiown — Support

Thank you for using Audiown.

## Getting started

1. Install Audiown from the App Store.
2. Open **Library** and tap **+** → **Add Files** or **Import Folder**.
3. Select audio on your device (e.g. `.m4b`, `.mp3`, `.m4a`).
4. Tap a book to play.

## Supported formats

Common formats include MP3, M4A, M4B, WAV, AIFF, and FLAC. For multi-part books, put files in one folder and use **Import Folder**. Single files with embedded chapter markers (often `.m4b`) show a chapter list in the player.

## Tips

- **Resume:** progress is saved per book automatically.
- **Sleep timer:** tap the moon icon on the player.
- **Skip intervals:** Settings → Playback Controls.
- **Several folders:** use **Add Files**, import one folder, then **Import more from another folder**.

## Troubleshooting

| Issue | What to try |
|-------|-------------|
| File won’t import | Confirm the file has an audio track; try opening it in Files first |
| No chapters shown | Chapters need embedded metadata (common in `.m4b`); plain MP3 may not have them |
| Playback stops in background | Check Low Power Mode; lock screen should show controls |
| Lost library after reinstall | Library is local; reinstall clears app data unless restored from a device backup |
