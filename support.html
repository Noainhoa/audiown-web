OneListen Support

Help for OneListen, an offline audiobook player for your own local audio files.

FAQ

How do I import files?

  1. Open OneListen.
  2. Open the Library.
  3. Choose Add Files.
  4. Select supported audio files from the iOS file picker.

How do I import a folder?

  1. Open the Library.
  2. Choose Import Folder.
  3. Select a folder that contains the parts of one audiobook.

What if a file was moved or deleted?

If OneListen cannot find a file, the file may have been moved, deleted, or made unavailable by the storage provider. Import the file or folder again from its current location.

Does OneListen work offline?

Yes. OneListen is designed for local files and offline playback. Your audio files remain on your device.

What playback features are available?

  • Playback progress restore.
  • Bookmarks.
  • Chapter or part navigation when available.
  • Playback speed controls.
  • Sleep timer.
  • Lock-screen and background audio controls.
